# CclAutoClick - 自动连点器

一个基于 JavaFX 和 JNA 的 Windows 平台自动连点器应用程序，支持多按键配置、多种触发模式和全局快捷键控制。

## 功能特性

### 核心功能

- **多按键支持**：可同时配置多个按键（鼠标左键、右键及键盘按键）进行自动连点
- **双触发模式**：
    - **HOLD 模式**：按住按键开始连点，松开停止
    - **TOGGLE 模式**：按一下按键开始连点，再按一下停止
- **全局快捷键**：可自定义全局启动/停止快捷键（如 F2），无需激活窗口即可控制程序
- **实时按键捕获**：通过界面点击按钮直接捕获想要设置的按键
- **配置持久化**：自动保存和加载配置，重启后保持设置

### 高级特性

- **独立参数配置**：每个按键可独立设置：
    - 启用/禁用状态
    - 点击间隔（毫秒）
    - 初始延迟（毫秒）
- **并发执行**：基于线程池的多任务调度，支持多个按键同时运行
- **输入过滤**：自动过滤自身产生的输入事件，避免递归触发
- **低延迟响应**：使用 JNA Hook 技术实现全局键盘/鼠标监听

## 技术栈

- **Java 21+**：核心开发语言
- **JavaFX**：图形用户界面框架
- **JNA (Java Native Access)**：Windows API 调用，实现全局输入监听和模拟输入
- **Maven**：项目构建和依赖管理

## 系统架构

```
┌──────────────┐
│  UI 层       │  ← JavaFX 界面控制器
└──────┬───────┘
       ↓
┌──────────────┐
│ 触发控制层   │  ← TriggerController (HOLD/TOGGLE 模式)
└──────┬───────┘
       ↓
┌──────────────┐
│ 状态机层     │  ← KeyStateMachine (每键独立状态)
└──────┬───────┘
       ↓
┌──────────────┐
│ 调度层       │  ← TaskScheduler (线程池管理)
└──────┬───────┘
       ↓
┌──────────────┐
│ 执行层       │  ← InputSender (JNA SendInput)
└──────────────┘
       ↑
┌──────────────┐
│ 监听层       │  ← GlobalInputListener (JNA Hook)
└──────────────┘
```

## 快速开始

### 编译打包

```bash
mvn clean package
```

生成的可执行文件位于 `target/CclAutoClick.exe`

### 运行

双击 `CclAutoClick.exe` 或运行 jar 包：

```bash
java -jar target/CclAutoClick-1.0-SNAPSHOT.jar
```

### 使用说明

1. **基本配置**：
    - 默认包含鼠标左键和右键两个固定配置项
    - 可通过"添加行"按钮增加新的按键配置
    - 点击"重新捕获"按钮可更改按键

2. **设置参数**：
    - 勾选复选框启用/禁用该按键
    - 修改"间隔"设置点击频率（单位：毫秒）
    - 修改"延迟"设置启动前的等待时间（单位：毫秒）

3. **选择触发模式**：
    - **按住激活**：按住配置的按键时持续连点，松开即停
    - **单击激活**：按一次开始连点，再按一次停止

4. **设置全局快捷键**：
    - 点击"点击设置"按钮
    - 按下想设置为启动/停止的按键（如 F2）
    - 之后可按此快捷键随时启动/停止程序

5. **启动连点**：
    - 点击"启动"按钮
    - 按照选择的触发模式操作按键
    - 点击"停止"按钮可立即停止所有连点

6. **配置管理**：
    - 配置会自动保存，下次启动时恢复
    - 也可手动点击"保存配置"或"加载配置"按钮

## 配置文件

配置文件存储在程序运行目录下的 `config.json`：

```json
{
  "triggerMode": "HOLD",
  "configs": [
    {
      "keyName": "MOUSE_LEFT",
      "enabled": true,
      "interval": 50,
      "delay": 0,
      "triggerMode": "TOGGLE"
    }
  ],
  "startStopHotkey": "KEY_F2"
}
```

## 注意事项

⚠️ **重要提示**：

- 程序需要管理员权限才能正确捕获全局输入
- 某些游戏或应用可能有反作弊机制，使用前请确认合规性
- 高频点击（<10ms）可能导致系统不稳定，建议间隔不低于 20ms
- 不要在重要文档编辑时使用，可能造成意外输入

## 常见问题

### Q: 快捷键无法捕获？

A: 确保以管理员身份运行程序，某些特殊按键可能不被支持。

### Q: 连点速度不准确？

A: Windows 定时器精度有限，极低间隔会有偏差，这是正常现象。

### Q: 如何完全退出程序？

A: 关闭窗口即可，程序会在后台清理资源后退出。
